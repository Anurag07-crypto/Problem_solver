10. Log & History Commands

View Commit History

bash
git log




One Line Log

bash
git log oneline




Beautiful Graph Log

bash
git log oneline graph all


Looks like:

bash
a1b2c3 Added login
d4e5f6 Fixed bug




11. Stash Commands

Save Temporary Changes

bash
git stash




Show Stashes

bash
git stash list




Restore Stash

bash
git stash apply




Remove Stash

bash
git stash drop




12. Advanced Git Commands

Rebase Branch

bash
git rebase main


Moves branch on top of another branch.



Cherry Pick Commit

bash
git cherrypick <commitid>


Copies one commit from another branch.



View Differences

bash
git diff




Compare Staged Changes

bash
git diff staged




Show Specific Commit

bash
git show <commitid>

18. Git Aliases (Productivity Boost)

Now use:

bash

Useful Aliases

bash

git config global alias.br branch
git config global alias.last "log 1 HEAD"
